# Honey Chain 🍯⛓️

Blockchain-Powered Honey Traceability & Smart Beekeeping (SIH 2026 Problem Statement SIH26021).

## Overview
Honey Chain is an end-to-end traceability and monitoring platform connecting beekeepers, processors, distributors, and consumers. It combines IoT-enabled smart beehive telemetry with an immutable cryptographic ledger and consumer QR verification.

## Features
- **Smart Beekeeping Telemetry**: Real-time hive monitoring (temperature, humidity, honey levels, pest risks).
- **Cryptographic Traceability**: SHA-256 block ledger recording harvests, processing stages, and distribution milestones.
- **Consumer Verification**: Instant batch lookup and QR verification for authentic honey origin.
- **Quality & Inspection Logs**: Lab tests, moisture content, pollen purity, and certification tracking.

## Tech Stack
- **Frontend**: React 19, TypeScript, TailwindCSS, Lucide Icons, Recharts, Leaflet
- **Backend**: Node.js, Express, SQLite (better-sqlite3)
- **Tooling**: Vite
